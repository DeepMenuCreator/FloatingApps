# Floating Launcher

Android-приложение для запуска других приложений в плавающих FreeForm-окнах. Идеально для AFK-ферм в Minecraft PE + TikTok/YouTube поверх игры.

## Функции

- **Плавающая кнопка** — перетаскиваемая кнопка "+" для быстрого добавления приложений
- **Ползунок включения** — включает/выключает плавающую кнопку
- **Список приложений** — добавленные приложения с кнопками:
  - **Запуск** — открывает приложение в FreeForm-окне
  - **Размер** — диалог настройки размера с предпросмотром
  - **Удалить** — убирает приложение из списка
- **FreeForm режим** — запуск приложений в отдельных окнах, которые можно двигать и растягивать

## Как использовать

1. Включи **"Включить плавающую кнопку"** — появится кнопка "+" на экране
2. Нажми **"+"** → выбери приложение (TikTok, YouTube и т.д.)
3. Нажми **"Запуск"** — приложение откроется в окне
4. Нажми **"Размер"** — настрой ширину и высоту окна с предпросмотром

## Важно: FreeForm

Для работы FreeForm-окон нужно:
- Android 7.0+ (Nougat)
- Включить в настройках разработчика: **"Force activities to be resizable"**
- Или через ADB: `adb shell settings put global enable_freeform_support 1`

На некоторых оболочках (MIUI, OneUI) FreeForm работает из коробки.

